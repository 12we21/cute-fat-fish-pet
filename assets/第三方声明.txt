8. Edge TTS（在线语音合成，可选、需要联网）
   服务方  ：Microsoft Edge 的在线语音合成服务（公开的 edge-tts 协议）
   说明    ：本包没有分发微软的任何代码或语音数据，只是在控制台打开「声音」
             并且联网时，按公开协议把要念的文字发给该服务、换回音频。
             该服务的使用受微软相关条款约束；不想联网就在控制台把声音关掉。

------------------------------------------------------------------------
9. 联网大模型 API（可选、需要主人自己填 Key）
   说明    ：只有在控制台填了「接口地址 + API Key」并切到「在线（联网模型）」
             或「自动择优」时，聊天与「看屏幕」的请求才会发往主人自己指定的
             服务商（例如 DeepSeek）。不填 Key、只用本机 Ollama 时全程不出本机。
             各家服务的条款与计费，由主人与其服务商之间约定。

------------------------------------------------------------------------
10. 隐私与数据（默认都在你自己电脑上）
   · 人设、记忆、聊天记录、截图缓存、日志：都在 %APPDATA%\BlueHairMaid\ 里
     （控制台上有按钮一键打开），卸载时会问你要不要一起删。
   · API Key：以明文保存在程序目录的 standalone\online.json，方便你自己改。
     这个文件不要发给别人；要换 Key 就在控制台里改。
   · 「看屏幕」：会把屏幕截图发给你自己配置的模型（本机 Ollama，或你填的视觉
     模型服务）。不打开这个功能就不会截屏。
   · 语音输入：SenseVoice 模型在本机跑，录音不出这台电脑。
   · 语音输出：用 Edge TTS 时文字会发到微软；关掉声音就完全不发。
   · 失败日志只写在本机 %APPDATA%\BlueHairMaid\logs\ 里。
