========================================================================
  可爱大肥鱼桌宠 · 使用说明
  一个独立运行的 Windows 桌面小女仆：不依赖任何别的软件，装完就能用。
========================================================================

【一、怎么装（挑一种就行）】

  ★ 方法一：安装程序（推荐，一路「下一步」）

    双击「可爱大肥鱼桌宠-1.0.0-安装程序.exe」→ 下一步 → 安装 → 完成。
      · 不需要管理员权限，默认装到 %LOCALAPPDATA%\BlueHairMaid
      · 想装到 D 盘：在「选择安装位置」那一步改成 D:\Apps\CuteFatFishPet 就行
      · 装完桌面和开始菜单会多一个「可爱大肥鱼桌宠」，双击它打开控制台
      · 卸载：设置 → 应用 → 可爱大肥鱼桌宠 → 卸载（也用安装目录里的 Uninstall.exe）

  方法二：免安装 zip（想自己折腾、或者要装到 U 盘）

    1. 把压缩包**完整解压**到一个文件夹（别直接在压缩包里双击）。
    2. 双击「安装.cmd」——它会问你「装到哪里？」：
         直接回车 = 默认 %LOCALAPPDATA%\BlueHairMaid
         想装到 D 盘/U 盘就粘贴一个路径，例如 D:\Apps\CuteFatFishPet
       （也可以命令行指定：install.ps1 -Target "D:\Apps\CuteFatFishPet"）
    3. 装完桌面会出现「可爱大肥鱼桌宠」，双击打开控制台，点「启动桌宠」。

  不想安装也可以：直接双击 standalone\start-pet.vbs 就能跑（绿色版）。

  第一次打开控制台，她会自己跑一遍适配（见下面第二节），不用你点任何按钮。

  数据（人设/记忆/设置）放哪也能自己定，四条规则从高到低：
    1) 环境变量 DSH_PET_DATA_DIR
    2) 程序目录里放 data-root.txt，里面写一行路径（绝对或相对程序目录）
    3) 程序目录里放空的 portable.txt → 数据放「程序目录\userdata」（便携）
    4) 默认 %APPDATA%\BlueHairMaid\
  控制台页脚会显示「人设与记忆」的完整路径，一眼能看到数据落在哪。

【二、第一次运行会自动做什么】

  第一次打开控制台，「本机适配」会**自己**跑一遍，不用你点任何按钮：
    · 认你的显卡和显存（读注册表 HardwareInformation.qwMemorySize，比 WMI 准）
    · 找本机的 Ollama，列出已经下载的模型
    · 按显存挑一对模型：一个负责聊天/碎碎念，一个负责「看屏幕」（视觉）
    · 把参数直接写进设置（上下文长度、显存腾挪、监测频率，弱机自动降频）

  十几秒后你会看到绿字「已经自动检测并设置好了：聊天 xxx · 看屏幕 xxx」，
  然后点「启动桌宠」就行。（想重新挑一次，就点「检测这台电脑」：
  先看结果，再点「按推荐设置好」。）

【三、一个模型都没有怎么办】

  两条路，控制台里都给了：
    A. 装 Ollama（https://ollama.com/download），回来点「启动 Ollama」，
       再点「帮我装一个小模型」（默认拉 qwen2.5vl:3b，约 3 GB，能聊天也能看图）。
    B. 用联网模型：在「联网模型（OpenAI 兼容）」里填接口地址 + API Key + 模型名，
       比如 DeepSeek：https://api.deepseek.com + 你的 key + deepseek-chat。
       然后把「AI 大脑」切到「在线」或「自动择优」。

  三档大脑的区别：
    在线 = 先走联网模型，本机 Ollama 不响应时自动兜回本机，不会卡死
    本地 = 只走本机，绝不偷偷联网
    自动择优 = 哪边能用走哪边

【四、她能干什么】

  · 说话：桌面气泡 + 语音输出（Edge TTS；出厂音色是「晓伊」，
           控制台「她的声音」里能改音色 / 语速 / 音高 / 音量，还能点一下就试听）
  · 听你说话：麦克风语音输入（本地 SenseVoice 识别，不上传）
  · 看屏幕：定时截屏并点评（本机视觉模型）
  · 性格：内置「蓝毛小女仆」「鲸鱼娘」两套人设，也能自己写一段存起来
  · 权限：允许她打开软件 / 打开文件和文件夹 / 打开网页（默认全关，你说了算）
  · 动手：直接在控制台终端说「打开B站」「开始录屏」「录屏位置 D:\录像」——
          这些是交给**她当前用的模型**去决定调哪个工具的
  · 录屏：自动找 OBS Studio / Xbox Game Bar / psr.exe，能改保存位置、起录停录
  · 唱歌、走位、右键菜单里的各种开关

【五、东西都存在哪】

  程序目录     安装目录（默认 %LOCALAPPDATA%\BlueHairMaid，装时可以自己选，可以整个删掉）
  人设/记忆/设置  %APPDATA%\BlueHairMaid\  （覆盖安装、升级都不会丢；可用 data-root.txt 改到别处）
  桌宠窗口数据   %APPDATA%\dsh-pet-electron-helper\ （每台电脑每用户一份）
  日志          %APPDATA%\BlueHairMaid\logs\ （控制台里点「打开日志」）

【六、常见问题】

  Q: 她说话很慢、电脑卡？
  A: 多半是两个模型一起挤显存。控制台「模型 · AI 大脑」里让「聊天/碎碎念」和
     「看屏幕用」选成**同一个**模型，最省显存也最流畅；或者把「AI 大脑」切到
     「在线」。显存小于 8 GB 时建议只用一个小模型。

  Q: 点「启动桌宠」没反应？
  A: 看 %APPDATA%\BlueHairMaid\logs\runner.err.log；杀毒软件也可能拦 Electron。
     也可以直接双击 standalone\start-pet.vbs 试试。

  Q: 语音输入没反应？
  A: 右键桌宠 →「语音模式」先打开；麦克风设备也在右键菜单里选。

  Q: 怎么彻底删干净？
  A: 用安装程序装的：设置 → 应用 → 可爱大肥鱼桌宠 → 卸载（或双击安装目录里的
     Uninstall.exe）。卸载时会问你人设/记忆要不要一起删，默认给你留着。
     用 zip 装的：双击「卸载.cmd」（或用安装目录里的 卸载.cmd），
     想连聊天记录一起删就用：powershell -File uninstall.ps1 -PurgeData

【八、她的隐私】

  · 人设、记忆、聊天记录、日志都在 %APPDATA%\BlueHairMaid\ 里，卸载时会问你要
    不要一起删（默认留着）。
  · API Key 是明文存在程序目录的 standalone\online.json —— 这个文件别发给别人。
  · 「看屏幕」会把屏幕截图发给你自己配置的模型（本机 Ollama，或你填的视觉模型）。
  · 语音输入在本机识别；语音输出用微软 Edge TTS 时文字会发到微软，关掉声音就不发。
  · 不填 Key、只用本机 Ollama 时，她全程不出这台电脑。
