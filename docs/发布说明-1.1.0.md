# 可爱大肥鱼桌宠 1.1.0 发布说明

上一版：1.0.0 · 本版：**1.1.0** · 她叫「蓝毛小女仆」

这一版**没有新功能**，做完的是三件「地基」上的事：把仓库变成干净、自洽、可以公开的独立源码仓库；
把控制桥的口子扎紧；把写死在代码里的本机路径清掉，并加了一道构建期门禁。

## 装

- **exe（推荐）**：双击，默认装到 `%LOCALAPPDATA%\BlueHairMaid`，不需要管理员权限；「选择安装位置」那一步可以改到别的盘。
- **zip（绿色）**：解压到任意目录，跑 `安装.cmd`（建快捷方式 + 写卸载登记），或者直接双击 `standalone\start-pet.vbs` 起、`standalone\stop-pet.vbs` 停。

**从 1.0.0 升上来**：直接装新版覆盖即可，**数据不用动**——人设、记忆、聊天记录、屏幕监测状态、桌宠的位置和大小都还在原处
（原因：`dsh-pet` / `BlueHairMaid` / `dsh-pet-*` / `/dsh-pet-7340` 这些内部标识**一个都没改**，见 [NOTICE](../NOTICE.md) 第 5 节）。
想干净一点也可以先卸载再装：卸载不删数据。

开桌宠还是老规矩：双击桌面快捷方式打开**控制台**，在控制台里点「启动桌宠」——控制台**不会**自动把她拉起来。

## 第一次打开会自己做的事

不变，仍然是那套「自动适配」：读显卡显存 → 列本机 Ollama 模型 → 挑聊天 / 视觉模型 → 写 `device-profile.json` 与 `screen-watch\state.json`，
并把随包的默认人设铺进数据根（**只补缺的，绝不覆盖你改过的**）。一个模型都没有也能跑，只是不开口。

## 电脑要求

- Windows 10 / 11 x64（桌面渲染端是 Electron 43，需要能跑 Chromium 的环境）
- 内存建议 8 GB 以上；要用本机模型的话显存越大越好（第一次运行会自动给一个保守档位）
- 不需要装 Node、Electron、Python——包里都带了
- 联网只在你用到这三样时才需要：联网大模型、Edge TTS、以及下载安装包本身

## 这一版改了什么（相对 1.0.0）

### 1) 仓库变成干净的独立源码仓库

- 去掉了「上游蓝本 + `overlay\` 覆盖 + `patch-app.mjs` 打补丁」那一整套机制：**`src\` 里就是成品源码**，
  打完所有历史补丁的最终状态，不再需要一份外部蓝本目录才能构建。
- 构建脚本重写为「按发布结构铺 `stage\`」：`build\build.mjs`（铺哪几块、`--list` 空跑、`--clean`、`--no-gate`）
  + `build\toolchain.mjs`（三块外部运行时 electron / node / speech 的定位，约 689 MB，不进 git）。
- 打包与发布脚本改成相对路径推导，不再依赖「打包机是 D 盘某个目录」这种前提。
- 仓库里补上了 `README.md`、`NOTICE.md`、`.gitignore` / `.gitattributes` 的整理，以及本版发布说明。

### 2) 控制桥加鉴权 + CORS 收紧

- 桌面渲染端在本机回环上开的**控制口**（控制台用它读状态 / 改权限 / 切语音）从 1.1.0 起带**共享密钥**：
  helper 启动时生成一个随机 token，落在数据根里的 `helper-control.json`（跟端口写在同一个文件）；
  控制台的每次读 / 写都要带 `Authorization` 与 `X-Pet-Token`，对不上就拒绝，并给出一句能照做的人话提示
  （「让桌宠重启一次再试」）。
- **CORS 收紧成白名单**：不再对任意来源开口，只认控制台自己的来源（`file://`，即 `Origin: null` 或缺失）与本机回环页面。
- 代码位置：`src\runtime\electron-helper\main.js` 的 `[bridge-auth@1]` 段落、`launcher\pet-api.js` 的 `[bridge-auth]` 段落。
- **免安装运行器的那个本地口也一起扎紧了**（`standalone\server.mjs`）：它原来是「任意来源 + `/shutdown` 连 GET 都能关掉她」，
  现在来源同样走回环白名单（不认识的来源一律 403 且不回 CORS 头），`/shutdown` 只收 POST 并要求同一把 token
  （token 每次启动随机生成，落在 `runtime.json` 里，只有本机进程读得到）；`standalone\stop-pet.vbs` / `stop-pet.mjs` 照旧能用。
  这样「某个网页里塞一张 `<img src="http://127.0.0.1:3080/shutdown">` 就能偷偷把她关掉」这条路就堵死了。

### 3) 去硬编码本机路径 + 构建期门禁

- 清掉了代码与文档里写死的本机路径（作者机器上的盘符、用户目录、临时目录），换成相对路径或环境变量推导。
- 新增构建期门禁 `build\check-paths.mjs`：**铺包之前**扫一遍要进包的内容，出现本机绝对路径 / 私人目录就拦下来
  （`node build\build.mjs --no-gate` 可跳过，不推荐）。
- 发布版自校验 `verify.mjs` 改成「独立仓库自校验」：核对整树指纹，并确认那些**不该进包**的东西真的不在
  （运行期状态、日志、联网 Key、上次的 pid 记录、数据根）。

### 4) 版本与文案

- `package.json`（根 / `src\` / `launcher\` / `src\runtime\electron-helper\`）的版本与说明文案更新到 1.1.0，
  产物名与版本号由 `src\package.json` 的 `version` 生成。
- `README.md`、`NOTICE.md`、`docs\`、`assets\使用说明.txt`、`assets\第三方声明.txt` 的口径统一成
  「由 Mikolu 独立开发和维护」+「特别感谢原作者 PC2005-cloud 在 0.3.0 版本提供的早期基础架构与灵感」。
- 上游署名完整性不变：`assets\LICENSE.txt`（上游 MIT 全文）原样随包分发，一个字都没删。

## 已知限制

- **没有代码签名**：首次运行 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。原因与替代方案见 [`关于代码签名.md`](关于代码签名.md)。
- **没有开机自启、没有自动更新**：要自启就把控制台快捷方式放进「启动」文件夹。
- **桌宠本体是 Windows x64**：包里带的是 win-x64 的 Electron / node / 语音引擎。
- 联网模型的 API Key 仍是**明文**存在程序目录的 `standalone\online.json` —— 别把这台机器的这个文件发给别人。
- 余额查询只实现了 DeepSeek 官方接口；别的服务商走「不支持」分支（不会假装成功）。
