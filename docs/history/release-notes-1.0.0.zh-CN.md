# 可爱大肥鱼桌宠 1.0.0（Windows x64）

一只住在桌面上的蓝发小女仆。这一版是**普通 Windows 用户拿到就能装**的整合包：
自带运行环境与离线语音，第一次打开会**自己看这台电脑适合用什么模型**。

## 下载

推荐用安装程序（**双击 → 一路「下一步」→ 完成**，不需要管理员权限）：

- 文件：`可爱大肥鱼桌宠-1.0.0-安装程序.exe`（331.8 MB）
- SHA256：`0D3699BCE8EFCD012839E0D4B18AD09AF8222FEF932B73E34CE899CA7DB89B86`
- 装到哪：默认 `%LOCALAPPDATA%\BlueHairMaid`，向导里那一步可以改成 D 盘等任意路径
- 装完：桌面 + 开始菜单出现「可爱大肥鱼桌宠」，双击就是控制台
- 卸载：`设置 → 应用 → 可爱大肥鱼桌宠 → 卸载`；会问你人设/记忆要不要一起删（默认留着）

喜欢绿色的、或者要装到 U 盘，就下 zip：

- 文件：`可爱大肥鱼桌宠-1.0.0-win-x64.zip`（397.7 MB，解压后约 761 MB）
- SHA256：`787B2003376C46D2BE08C07F1D4B2D7BD5D7D8593E7F7736914D15E3B8C31C2A`
  （校验：`certutil -hashfile 可爱大肥鱼桌宠-1.0.0-win-x64.zip SHA256`）

## 装

**安装程序（推荐）**

1. 双击 `可爱大肥鱼桌宠-1.0.0-安装程序.exe`。
2. 一路「下一步」；想换盘就在「选择安装位置」那一步改，或者点「浏览」挑一个文件夹。
3. 安装完成页上那个勾默认是打上的，点「完成」就直接打开控制台 → 点「启动桌宠」，那只鱼就出现在桌面右上角了。

**免安装 zip**

1. 解压 zip 到任意位置（解压出来是一堆文件夹，**不要**只在压缩包里双击）。
2. 双击 `安装.cmd` → 会问装到哪儿（可以直接粘贴一个路径，回车用它默认的）→ 几秒钟装完。
3. 桌面出现「可爱大肥鱼桌宠」，双击打开控制台 → 点「启动桌宠」。
4. 卸载：双击安装目录里的 `卸载.cmd`（或用 `安装.cmd` 旁边那个 `卸载.cmd`）。**人设和记忆不会删**。

## 第一次打开会自己做的事

- 看显卡显存、看本机有没有 Ollama、有哪些模型 → 挑一个能跑得动的聊天模型和一个视觉模型，
  按显存算好上下文和看屏幕的频率，写成 `device-profile.json`。全程不用点按钮。
- **本机一个模型都没有**：不会偷偷联网。控制台会告诉你两条路 —— 装 Ollama 拉个小模型（本机跑、不要钱），
  或者填一个联网 API Key（OpenAI 兼容，比如 DeepSeek）。选哪条由你决定。
- 语音是**随包带的**（sherpa-onnx + SenseVoice），听你说话完全离线；她说话用的是微软 Edge 在线合成
  （音色、语速、音高都能在控制台「她的声音」里改，出厂是「晓伊 + 正常语速 + 不升调」）。

## 电脑要求

- Windows 10 / 11 64 位；装完约 761 MB，加上模型和记忆建议留 2 GB 以上。
- 显卡不是必须的：没有独显就选小模型（控制台会自己挑）。
- 想让她在本机跑模型：装 [Ollama](https://ollama.com)，`ollama pull qwen2.5vl:3b` 之类的小模型就够用。
  不想装就用联网 API。

## 能改的东西

- **装到哪 / 数据放哪**：安装时可以直接粘路径；数据默认在 `%APPDATA%\BlueHairMaid`，
  想让数据跟着程序走就在程序目录放一个 `portable.txt`，想放别处就放 `data-root.txt`（第一行写路径）。
- **她叫什么**：控制台「名字 · 外观」，或者终端里敲 `名字 新名字`。
- **性格**：控制台「性格」区，写一段「她是谁、什么语气、爱做什么动作」，或者从性格库里存/取。
- **模型**：控制台「模型 · AI 大脑」，在线 / 本机 / 自动择优三种，聊天和看屏幕可以分开选。
- **录屏 · 浏览器**：用哪个录屏软件、存到哪、打开哪个网站，写在控制台「录屏 · 浏览器」里，
  她动手的时候会自己按设置来。
- **终端**（控制台底部）：`检测` / `测速` / `录屏 开|停` / `打开B站` / `音量 0.5` / `音高 软萌` …，敲 `帮助` 看全部。

## 这一版修过 / 加过的地方（相对上游 dsh-pet）

- **第一次运行自动适配**：显卡显存、Ollama 模型清单都自己看，挑好聊天与看屏幕的模型再写设置。
- **联网模型**：控制台里填「接口地址 + API Key + 模型名」就自动切到「在线（联网模型）」；Key 清掉就自动回「自动择优」，不会偷偷联网。
- **看屏幕的视觉模型可以单独配**：自己的接口地址 + 自己的 Key（比如 `deepseek-flash`）。没配齐时她会直接说「还没配看屏幕的模型」，而不是把截图硬塞给纯文本模型瞎编。
- **问话优先回**：等你这句话的回复期间，碎碎念和自言自语会自动让路；万一没接上，她会说出来（「刚才那句没接上…」）而不是装死不吭声。
- **「查看余额」只有在真的接了联网模型时才有意义**：没配 Key 时控制台会把它灰掉，菜单里也不会出现这一项。
- **音色名字精简**：下拉里只留「晓伊 · 活泼软萌」这类短名字，音色、语速、音高、音量都能自己改。
- **右键菜单与控制台联动**：两边改的是同一份设置，改完立刻生效，终端里那几条口令（`看着点` / `别看了` / `换本地` / `换在线` / `自动择优` / `碎碎念模式` / `只说高光` / `只听我的`）现在真的会切换状态。
- **隐私排雷**：语音日志、自检录音、缓存目录改成跟着你自己的数据目录走（上游写死的是原作者的家目录）；开发期草稿堆（`patched\`）不进发布包；包里没有任何 API Key。
- **升级认得旧家**：装过一版之后再跑新安装程序，「选择安装位置」里自己填的就是上次那个目录（读「应用和功能」里的登记项），不会再装出第二份 761 MB；想换地方也可以自己改。
- **隐私与数据写清楚了**：`第三方声明.txt` 新增「Edge TTS（联网合成）」「联网大模型 API（你自己的 Key，只发往你指定的服务商）」「隐私与数据（数据在 `%APPDATA%\BlueHairMaid`，Key 明文存 `standalone\online.json`，看屏幕会把截图发给配置的模型，语音识别本机跑，日志只在本机）」三节；`使用说明.txt` 加了对应的「她的隐私」一节，README 也有「隐私与数据」一段。

## 已知限制

- 没有开机自启和自动更新；安装程序没有代码签名证书（Windows 可能弹「未知发布者」蓝框，点「仍要运行」就行；想自己签一份看 `docs\code-signing.zh-CN.md`）。
- 她那句话是微软 Edge 在线合成，**断网时不会说话**（听你说话不受影响，模型也可以本机跑）。
- 打包里不含 Ollama，也不含任何模型权重。
